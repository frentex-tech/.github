# Reporting a security concern

Please do not disclose credentials, private data or unpatched security issues in public issues or pull requests.

Email **INFO@frntextech.com** with the affected repository or page, a concise description, reproduction steps using non-sensitive data, and the potential impact. Do not attach live credentials or customer records.

Support scope and response arrangements for private client systems are defined in the relevant engagement. This document does not establish a public response-time guarantee or a bug bounty program.
